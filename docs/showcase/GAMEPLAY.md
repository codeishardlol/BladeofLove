# 玩法详解

[返回游戏介绍](../../README.md)

## 构筑发生在三个层面

- **角色层**：六人编队、阵型、目标策略、技能、装备与成长。
- **队伍层**：祝福接力、护盾循环、反应回能与普攻蓄势，把不同角色的动作连接起来。
- **战场层**：造物、天气与中立装置改变全场规则，让同一队伍面对不同的时机与风险。

战斗采用自动行动时间线。玩家主要在战前与节点之间作出构筑选择；下面的预警与争夺机制影响编队和技能节奏，不表示已有即时手动走位操作。

## 一些机制例子

| 机制 | 能带来什么选择 |
|---|---|
| 烛灵 | 不占编队位置，独立发射火球并分担我方直接伤害；它有生命，会阵亡，不能代替整队存活。 |
| 野火祭台 | 提供独立的周期火球，不需要等角色完成施法。 |
| 涨潮／退潮 | 涨潮让敌我全员潮湿，火、冰、雷因此拥有不同的反应条件。退潮不会立即清空已有附着。 |
| 黑夜与引路灯 | 黑夜让双方精确索敌失效、改为随机选择存活敌人；引路灯为我方提供应对。 |
| 雷雨线圈 | 对全场潮湿者周期放电，敌我都受影响。伤害能力必须与生存能力一起考虑。 |
| 游离灵泉 | 最后施法的一方取得控制权，周期治疗该方最虚弱的存活单位；敌方也能夺取。 |
| 巡游落星 | 依次预告阵线，延迟后轰击该线敌我双方。护盾与队伍承压能力决定收益和代价。 |
| 回声碑 | 记录最后一次技能伤害命中，延迟回放到记录方的对面。敌方能够覆盖我方记录，每份记录仅消费一次。 |

场地计时跟随有效战斗时间，技能演出锁定和暂停期间不会继续偷偷结算。

## 商人、事件与路线

商人提供对话、补给、机制祝福与解除服务；旅途事件提供资源交换与带代价的选择，也保留不接入装置的选项。

两张地图各增加了八个可选试验节点，从烛灵工坊、泵房与补给站，到遗迹实验室、灵泉／回声碑／落星试验。玩家可以在这里接触新规则，再尝试带进自己的构筑。

## 角色与剧情

主线围绕失踪小队、旧塔的重启协议、分布式灯网与真实的下一天展开。全部11位五星角色分担调查、救援、守备、修复、记录与最终交接，不仅作为结尾露面的角色。

剧情支持双全身像、说话人高亮、逐字文本、自动播放、回看和跳过。主线按累计战绩与部分节点／等级条件推进；战败和重来另有解释与对话，已保存的故事不会在每轮归零。
