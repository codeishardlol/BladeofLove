# 项目说明

[返回游戏介绍](../../README.md)

- 名称：Blade of Love / 黎明之城的守望者
- 类型：横版编队自动战斗肉鸽
- 目标平台：Windows PC
- 当前维护引擎：Unity 6000.1.17f1 / C#
- 展示版本：本地开发版0.29.0
- 截图更新：2026-09-11

## 公开仓库的定位

这里用于介绍游戏、展示实机界面与收集建议。只发布经过筛选的文档和压缩截图，不上传完整开发历史、存档、构建缓存、原始大图集或第三方授权音频。

当前没有开箱可运行的源码工程或发行包。后续若提供试玩、源码或素材授权，会单独说明范围与使用方式。

## 当前已实现

- 六人编队、七元素附着与反应、装备和技能成长。
- 商人对话、祝福购买与解除、可配置旅途事件。
- 独立烛灵、火焰祭台、潮汐、夜幕、照明与雷雨装置。
- 灵泉控制权、回声碑覆盖与巡游落星预警。
- 24章主线、3段战败幕、2段重来幕；232段对白覆盖11位五星角色。
- 双全身立绘对话、自动阅读与故事回顾。

## 截图说明

`images/` 内均为当前Unity工程运行时截图，使用隔离展示存档。展示存档开放了角色与装备以方便查看页面，未覆盖开发者的真实游戏进度。战斗截图由同一帧的世界摄像机与UI渲染层合成。

截图中的部分造物形象与剧情背景属于占位演出。后续主要补充正式造物动画、专属剧情CG、角色表情差分及音画细节。
